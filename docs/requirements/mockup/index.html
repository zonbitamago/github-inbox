見ていただきたいこと

  1. PR の一覧: 1つにまとめ、更新の新しい順に並べ、自分待ちは理由のラベルだけで示す形にしました（D-016）。「自分待ちの理由あり」での絞り込みも加えています
  2. 出来事の一覧の日数: PR の一覧の期間とは別に選べるようにしました（出来事の一覧の上と設定）
  3. 画面の並べ方: 設定で選べるようにしました（下のボタンでも切り替えられます）
  4. すべてのリンクをコピー: PR の一覧の上に加えました。一覧に出ている PR（検索・絞り込み後）のリンクを、表示の順にコピーします（D-017）
  5. 出来事が1日数十件並んだときに、1行の情報量で読めるか
  6. 「受け取れていない」表示や、閉じていた間の出来事の区切りの目立ち方
  7. その他、触ってみて違和感があるところ

画面の並べ方

S できれば／C あれば。印の無いものは M（必須）です。

出来事を起こす

レビュー依頼を起こすと、PR の一覧にはリロードするまで出ません（D-013）。設定でその種類のデスクトップ通知をオフにすると、一覧にだけ載ります。

受け取れない状態

受け取れない間に起こした出来事は、受け取れるようになったときに一覧に載ります（デスクトップ通知は出しません）。

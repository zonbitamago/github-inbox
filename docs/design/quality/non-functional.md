## 1. 前提

| 項目 | 内容 |
| --- | --- |
| 構成 | サーバーを持たず、各自の PC のアプリが直接 GitHub に問い合わせる（ADR-001）。出来事の起点は GitHub の通知 API（ADR-002） |
| 利用者 | 依頼者とチームの希望者（10人前後）。各自の PC・各自の GitHub アカウントで使う。利用者どうしの同時接続という考え方は無い |
| 開発体制 | 1人 + AI 1体の直列（D-002）。**分割のしやすさ（並列実装のための保守性の目標）は置かない**（設計フレーム ⑨「分割容易性を非機能として扱うか」） |
| 業務担当に聞く定番の項目 | サーバーが無いため、データを失ってよい時間（RPO）・止まってよい時間（RTO）は当てはまらない。手元の保存が壊れても GitHub から取り直せる（Q-09）。可用性は GitHub に依存する |

## 2. 品質特性の優先順位

intent.md の成功の合図（S1: 5分以内に気づける、S2: 自分待ちが1画面で分かる）と、「軽さより使い心地を優先」（NF-04）から決めた。

| 品質特性 | 優先度 | 理由 |
| --- | --- | --- |
| 機能適合性（機能正確性・機能完全性） | 高 | 出来事の取りこぼしや種類・自分待ちの理由の取り違えは、S1・S2 を直接損なう |
| 性能効率性（時間効率性） | 高 | 5分以内（S1）、PR の一覧の5秒以内（NF-03） |
| 信頼性（成熟性・障害許容性・回復性） | 高 | 1日中立ち上げたまま使う。GitHub やネットワークが止まっても、受け取れていないことが分かり、戻れば追いつく |
| セキュリティ（機密性） | 高 | トークンは `repo` スコープ（読み書きを含む）を持つ（ADR-002）。会社のプライベートリポジトリの内容を扱う |
| 使用性（運用操作性・習得性・UI 快美性） | 高〜中 | 切り替えてすぐ見られること・手順書を見ずにアプリの案内で使い始められることは高。見た目（UI 快美性）は中（4.） |
| 性能効率性（資源効率性） | 中 | GitHub の利用制限は守る（高）。メモリ・CPU は上限を置かず目安だけ（NF-04） |
| 移植性（適応性・設置性） | 中 | Mac と Windows で動く。Windows は確かめていない（D-021） |
| 互換性（共存性） | 中 | GitHub の利用制限を gh CLI など同じアカウントの他の道具と共有する |
| 保守性 | 中 | 直列で、将来はチームで手を入れる可能性がある程度 |
| 使用性（アクセシビリティ） | 低 | 要件に挙がっていない。キーボード操作などは標準の部品の範囲で配慮する |

## 4. UI 快美性の優先度と design-system.md

- 優先度: **中**。社外に出す製品ではないが、依頼者は「ユーザー体験を一番に考えたい」とし、見た目を決めずにおくと AI が推測で配色などを決めてしまうため
- ⑪ で design-system.md v0（仮）を起票する。中身は「方向」（例: OS になじむ落ち着いた見た目）と、配色・書体・余白・角丸の少数の決まり（ライトとダークの両方）。部品の細かな見た目までは前倒ししない
- 実際の見えの良し悪しは、実装中に実機の画面で依頼者が判断し、design-system.md に書き戻す

## 6. 引き継ぎ事項

### ⑩ へ

- 問い合わせの間隔と回数の管理（Q-01・Q-04・Q-06）を1か所にまとめる部品（メインプロセス）
- 出来事の分解・種類の判定・自分待ちの理由の判定を、GitHub への問い合わせから切り離した純粋な処理にして、単体テストで網羅できる形にする（Q-08・Q-16）
- 保存の形式と、古い出来事の削除・壊れたときの立ち直り（Q-09）
- PR の一覧を少ない問い合わせで取る方法（GraphQL の検索で、レビューの状態とチェックの結果を一度に取るなど）（Q-02）
- ログの部品（Q-15）

### ⑪ へ（⑪ で書いた。`docs/design/conventions/`。Mac 用は両対応の1つにした（ADR-014））

- design-system.md v0（Q-17）
- セキュリティの規約（Q-10・Q-11・Q-12）とテストの規約（test-strategy.md）
- 配布ページに対応 OS を明記する（Q-13）
- Mac 用の配布物は Apple Silicon と Intel の両方（または両対応の1つ）をビルドする。Windows 用は x64（必要なら arm64 も）（Q-13）

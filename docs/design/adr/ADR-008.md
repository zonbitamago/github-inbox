# ADR-008: Mac は DMG（ドラッグ＆ドロップでアプリケーションフォルダへ入れる形）、Windows は利用者ごとに入れるインストーラーで配る

## ステータス

採用（2026-11-26 技術者が確認。依頼者の相談を受けた AI の提案）

## コンテキスト

- 手順書を見なくてもインストールすれば使える形を目指す（D-024、F-36）
- Mac では、アプリがアプリケーションフォルダにないとデスクトップ通知が失敗する（試作で確認。review/spike-unsigned-electron-mac.md）
- 依頼者から「よくある Mac のアプリのように、アプリケーションフォルダにドラッグ＆ドロップで移す形にできないか」と相談があった
- 署名はしない（C-03）。配布は GitHub Releases（ADR-005）。対応 OS は macOS 13 以降と Windows 10・11（64bit）（C-07）
- 会社の PC では、管理者の権限が無い利用者もいる可能性がある

## 決定

- Mac 用は **DMG** で配る。開くと本アプリと「アプリケーション」フォルダへのショートカットが並び、ドラッグ＆ドロップで入れられる形にする。Apple Silicon と Intel の両対応の1つ（universal）を作る（⑪ で決めた。ADR-014）
- それでもアプリケーションフォルダの外（DMG の中やダウンロードフォルダ）から開かれた場合に備え、アプリが移動を勧めて移す（F-36 (1)。Electron の `app.isInApplicationsFolder()`・`app.moveToApplicationsFolder()` を使う想定。⑩.2 で確かめる）
- Windows 用は、**利用者ごとに入れるインストーラー**（electron-builder の NSIS。管理者の権限が要らない形）で配る。スタートメニューへの登録を行う
- 作るのは electron-builder で、GitHub Actions の Mac と Windows のランナーでビルドする（ADR-005。設定の詳細は build-and-release.md）

## 理由

- DMG のドラッグ＆ドロップは Mac で広く使われている形で、利用者が迷いにくい。手順書を見ずに入れられる（D-024）
- アプリケーションフォルダに入るため、デスクトップ通知が失敗する状況を避けられる
- 利用者ごとに入れるインストーラーなら、会社の PC で管理者の権限が無くても入れられる
- Windows のデスクトップ通知には、スタートメニューへの登録（アプリの識別子の登録）が要る。インストーラーがこれを行う
- どちらも electron-builder が標準で作れ、署名しなくても作れる

## 検討した代替案

### 代替案A: Mac も zip で配り、アプリが移動を勧める

- メリット: 作るものが簡単
- 採用しなかった理由: 利用者がダウンロードフォルダから直接開きやすく、移動の案内に頼ることになる。依頼者が求めた「よくある Mac のアプリ」の形と違う

### 代替案B: Windows を、インストール不要の形（portable）で配る

- メリット: インストーラーを通さずに使える
- 採用しなかった理由: スタートメニューへの登録が無く、Windows のデスクトップ通知が出ないおそれがある。置き場所も利用者任せになる

### 代替案C: Windows を、PC 全体に入れるインストーラーで配る

- メリット: 一般的なインストール先に入る
- 採用しなかった理由: 管理者の権限が要り、会社の PC では入れられない利用者がいる可能性がある

## 結果（トレードオフ）

- ✓ Mac は、ドラッグ＆ドロップでアプリケーションフォルダに入れられ、デスクトップ通知が失敗しにくい
- ✓ Windows は、管理者の権限なしで入れられ、デスクトップ通知に要る登録も行われる
- ✗ ドラッグして入れても、初めて開くときの Gatekeeper の警告（Mac）と SmartScreen の警告（Windows）は出る。配布ページの短い説明で案内する（F-30）
- ✗ Mac 用の DMG は両対応の1つにするため、片方だけのものの約2倍の大きさになる（ADR-014）
- ✗ **Windows のインストーラーとデスクトップ通知の振る舞いは確かめていない**（D-021）
- ✓ Mac の利用者は全員が管理者の権限を持つため、`/Applications` へのドラッグ＆ドロップで入れられる（依頼者に確認。D-028）。試作は `~/Applications` だけで確かめたので、`/Applications` に置いたときのデスクトップ通知は ⑭ で確かめる（⑫ の DR-07 で追記）
